# obsidian-ios-sync

Самодельная синхронизация vault'а Obsidian между iOS и ПК, без официального Obsidian Sync.

Состоит из двух частей:

- **`server/`** — маленький HTTP-сервер на Bun. Хранит файлы vault'а и их метаданные
  (хэш, mtime, "надгробия" удалённых файлов). Запускается один раз на ПК/NAS.
- **`plugin/`** — плагин Obsidian (TypeScript, работает и на десктопе, и на iOS, т.к.
  использует только Vault API и `fetch`/`crypto.subtle` — никакого Node.js). Ставится
  в оба vault'а (на ПК и на телефоне) и синхронизирует их через сервер.

## Как это работает

Каждый файл в syncState хранит хэш на момент последней успешной синхронизации — это
"общий предок" (merge base). При каждом sync-проходе плагин делает трёхстороннюю
сверку: локальный файл / файл на сервере / общий предок — как в git. Это позволяет
понять, какая сторона реально изменилась, без необходимости доверять системным часам
разных устройств.

- Изменился только локально → загрузка на сервер.
- Изменился только на сервере → скачивание.
- Удалён на одной стороне и не менялся на другой → удаление распространяется.
- Изменился и там, и там (настоящий конфликт) → локальная версия остаётся "главной",
  а версия с сервера сохраняется рядом как `Заметка (sync-conflict 2026-...).md`,
  ничего не теряется молча.

`.obsidian/`, `.trash/` и `.git/` по умолчанию не синхронизируются (настраивается).

## Быстрый старт

### 1. Сервер (на ПК или NAS)

```bash
cd server
bun install         # зависимостей нет, но добавит bun-types для тайпчека
SYNC_TOKEN=<длинный-случайный-секрет> PORT=8787 DATA_DIR=./data bun run start
```

Сервер слушает `0.0.0.0:8787` без TLS и с простым Bearer-токеном — этого достаточно
только в доверенной сети. Чтобы достучаться с iPhone откуда угодно, **не пробрасывайте
порт в интернет напрямую** — поднимите сервер поверх приватной сети, например
[Tailscale](https://tailscale.com/) или WireGuard, либо поставьте перед ним reverse
proxy с HTTPS (Caddy/nginx) хотя бы в своей локальной сети.

Для автозапуска на ПК заверните команду в systemd unit / launchd / Task Scheduler —
в этом MVP это не сделано намеренно, чтобы не привязываться к конкретной ОС.

### 2. Плагин (десктоп и iOS)

```bash
cd plugin
bun install
bun run build   # соберёт main.js рядом с manifest.json
```

Скопируйте `manifest.json` и собранный `main.js` в
`<vault>/.obsidian/plugins/vault-sync-lite/` — на ПК напрямую, на iOS через
Files-приложение / iCloud Drive / любой способ, которым вы обычно кладёте файлы в
vault. Включите плагин в Obsidian → Settings → Community plugins.

Проделайте это в **обоих** vault'ах (ПК и телефон) — это один и тот же билд, плагин
кроссплатформенный.

### 3. Настройка

В настройках плагина на каждом устройстве укажите:

- **Server URL** — адрес сервера (например, Tailscale IP: `http://100.x.x.x:8787`).
- **Token** — тот же `SYNC_TOKEN`, что и на сервере.
- **Auto sync** / **Sync interval** — период фоновой синхронизации.

Кнопка **Test** проверяет доступность сервера, **Sync** запускает синхронизацию
вручную. Есть также команда `Sync now` в палитре команд.

## Разработка

- `plugin/`: `bun run dev` — esbuild в watch-режиме.
- `server/`: `bun run dev` — перезапуск при изменениях.
- Тайпчек: `bunx tsc --noEmit -p tsconfig.json` в соответствующей папке.

## Известные ограничения (осознанно, для MVP)

- Один сервер = один vault. Для нескольких vault'ов — несколько инстансов/портов.
- Нет TLS/шифрования на сервере — используйте VPN (Tailscale) или reverse proxy.
- Синхронизируется только содержимое vault'а, не `.obsidian/` (темы, плагины,
  hotkeys) — осознанно, чтобы не ловить конфликты конфигов между платформами.
- Конфликты разрешаются по правилу "локальный файл главный, чужая версия — рядом
  копией", без ручного merge UI.
